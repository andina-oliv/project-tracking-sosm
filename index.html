For local testing use http://localhost:8000/api. For team members across office WiFi/LAN, enter your computer's IP, e.g. http://192.168.1.100:8000/api.

Panduan Cepat XAMPP & Laravel Backend:
  1. Buka XAMPP Control Panel dan klik Start MySQL (Port 3306).
  2. Buka phpMyAdmin (http://localhost/phpmyadmin) & buat database: pt_sosm_tracking.
  3. Di terminal folder backend jalankan: php artisan migrate --seed
  4. Nyalakan server Laravel: php artisan serve --host=0.0.0.0 --port=8000
  5. Klik tombol Test Connection di bawah, lalu klik Save & Connect!

Obtained after deploying the script in your shared Google Sheet (file google-apps-script.js).

Quick 2-Minute Setup Guide:
  1. Open your Google Sheet or Google Drive.
  2. Click Extensions > Apps Script.
  3. Paste the code from google-apps-script.js (or click Copy button above).
  4. Click Deploy > New deployment > Web app.
  5. Set Execute as: Me and Who has access: Anyone.
  6. Click Deploy, copy the Web App URL, and paste it into the field above!
